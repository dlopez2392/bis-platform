Things to notice. The sentence is generated from the same rows as the tiles, so it can never disagree with them; it names the top source and top page only when one clearly leads, and says "roughly the same as" instead of a percentage when the change is under 5%. Weekend bars are muted so the weekday rhythm reads at a glance. "Where they were" shows cities when Vercel gives them, else states; the last row rolls up the rest as "Elsewhere".
